## 项目一句话

把一条视频链接（或一段分享文案）变成**客户能直接打开的视频文件 / 网盘链接**：
链接识别 → 短链展开 → 多剧集展开 → 下载 → 去水印 → 上传 → 回话，
全流程跑在本地，自带网页控制台，可打包成单文件 exe。


## 三条最重要的设计约束

1. **不依赖任何第三方付费解析服务**（曾用过 TikHub，已整体移除，见 [01 第 5 节](01-需求与范围.md)）。
2. **测试必须离线可跑**：真实网络只用于人工验收，自动化测试一律打本地 HTTP 服务器。
3. **默认不碰用户环境**：不装证书、不改系统代理、不启动浏览器；抓包/注入这类有副作用的通道**默认关闭**，必须显式开启。
